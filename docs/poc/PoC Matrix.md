## Explicit split and metric interpretation

- SELENE splits group `package_name`, so all claims for a package remain together. The holdout seeds are alternative grouped manifests; they are not independent datasets.
- The label is whether the paired target context has the same released processed flag. It is not behavior truth, malware status, or proof of capability.
- Brier, log loss, and average precision are computed on the same source-positive held-out claims. Because recurrence prevalence is 85–90%, AP must be read against persistence and prevalence baselines.
- Bootstrap intervals use 300 package-cluster resamples as a discovery-stage stability check. The confirmatory design should use the roadmap’s larger frozen bootstrap and the same package resample for paired comparisons.
- Fixed coverage uses held-out score ranking. It is a retrospective risk/coverage description, not a calibration-only policy and not a formal risk guarantee.
- The two SELENE seeds, count/volume model variants, normalized-count variants, and negative controls are all retained in `temp/`; nothing was selected by deleting an unfavorable run.
