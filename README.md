# CASE-Android

## Context-Aware Scoping of Recorded Android Behavioral-Security Evidence Across OS Versions

CASE-Android explores how reports can scope recorded behavioral-security evidence to the execution context in which it was observed. The initial empirical setting is recorded Android 10/API 29 and Android 14/API 34 evidence from SELENE.

The project concerns recorded evidence and context-aware evidence scoping—not malware truth or universal Android portability. It is not currently an FL or IoT experiment. Its PhD connection is conceptual: heterogeneous contexts can produce unequal security-evidence reliability, a concern relevant to collaborative malware detection using federated learning across heterogeneous IoT devices.

Datasets are kept externally and are not committed to this repository. In particular, the MIT license below covers original CASE-Android code and repository material only; SELENE, ARTEMIS, and other third-party datasets or artifacts retain their own licenses and attribution requirements.
